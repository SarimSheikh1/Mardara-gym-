# IronPulse Fitness

Original premium gym website and management-system foundation.

## Run locally

Requires Node.js 18+.

```bash
npm start
```

Open `http://localhost:3000`. The starter is intentionally dependency-light so the UI can be reviewed immediately. The health endpoint is available at `/api/health`.

## Roadmap

The visual foundation is in `index.html`. The next layers will add persistent data models, authentication/RBAC, member management, attendance, billing, ledgers, reports, trainer/member dashboards, uploads, and print-ready receipts.
